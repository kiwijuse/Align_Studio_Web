# 깨진 것들

> 만들면서 실제로 부순 것과 원인

---

원인이 예상과 다른 데 있던 것만 골랐습니다.
"오타였다" 같은 건 뺐습니다.

---

## 첫 화면에서 아무것도 안 눌렸다

배포된 사이트에서 **첫 화면의 모든 버튼이 죽어 있었습니다.**
로컬에서는 멀쩡했습니다.

원인은 화면이 아니라 **배포 스크립트**였습니다.
JavaScript 에서 `$` 는 흔한 함수 이름이고, 셸에서 `$` 는 변수 기호입니다.

```js
$('#login')      →      1366('#login')
```

`1366` 은 그때 돌던 프로세스 번호였습니다.
스크립트가 파일을 옮기면서 `$(` 를 명령 치환으로 해석해 버린 것입니다.

**원본은 처음부터 멀쩡했고 배포본만 죽어 있었습니다.**
그래서 원본을 아무리 봐도 원인이 안 보였습니다.

배포 후 검사를 하나 넣었습니다.

```powershell
# 숫자가 함수처럼 불리고 있으면 — $ 가 먹힌 것이다
$m = [regex]::Match($t, '(?<![\w.$])\d+\s*\(\s*[''"]')
if ($m.Success) { $fail += "숫자 호출: $($f.Name)" }
# 함수 이름이 통째로 사라진 경우
if ($t -match '(?m)^\s*\(\s*[''"][#.]') { $fail += "이름 없는 호출: $($f.Name)" }
```

처음 만든 검사는 `^\s*\.\w+` 로 잡아서 `.then(` 같은 **정상적인 메서드 연결까지** 걸렸습니다.
6건이 헛걸렸습니다. **검사가 시끄러우면 아무도 안 봅니다.**
숫자가 함수 자리에 온 경우와 이름이 사라진 경우만 남겼습니다.

> **배운 것 —** 로컬과 배포본이 다르게 동작하면, 코드가 아니라 **그 사이의 파이프**를 본다.

## 상담 창이 첫 화면 뒤에서 열렸다

첫 화면의 `상담으로 진단받고 싶어요` 를 눌렀는데 **아무 일도 안 일어났습니다.**

실제로는 창이 열리고 있었습니다. **첫 화면 뒤에서** 열렸을 뿐입니다.

| | z-index |
|---|---:|
| `#login` | **960** |
| 창을 앞으로 가져오는 코드 *(인라인 스타일)* | **21** |

인라인 스타일은 CSS 규칙보다 강하지만, **숫자가 작으면 소용없습니다.**
창을 앞세우는 함수가 모든 창에 21을 쓰고 있었고 그건 첫 화면 아래였습니다.

```css
z-index: 975 !important;   /* 게이트(960) 위로 */
```

**이걸 한동안 못 찾은 이유가 더 중요합니다.**
모바일 폭에서만 확인했기 때문입니다. 모바일에서는 첫 화면과 상담 창의
쌓임 맥락이 달라서 문제가 드러나지 않았습니다.

> **배운 것 —** 겹침 문제는 화면 폭마다 다르게 나타난다. 한쪽에서 됐다고 다 됐다고 하면 안 된다.

## 아이콘 반짝임이 아예 안 돌았다

바탕화면 아이콘이 차례로 밝아지는 연출이 있습니다. **한 번도 안 돌았습니다.**

`requestAnimationFrame` 안에서 시작하도록 돼 있었는데
브라우저는 **화면에 보이지 않는 탭에서 이걸 부르지 않습니다.**

문제는 그 앞에서 "연출 끝남" 표시를 이미 켜둔 것이었습니다.
탭으로 돌아와도 "이미 했다"고 판단해 영영 돌지 않았습니다.

```js
setTimeout(function () { ... }, 0);   // rAF 대신
```

한 프레임 미루는 것이 목적이었지 **그림이 그려지는 것을 기다릴 필요는 없었습니다.**

> **배운 것 —** `requestAnimationFrame` 은 "다음 프레임"이 아니라 "다음에 그릴 때"다.
> 안 그리면 안 온다.

## 길잡이가 두 번 등장했다

길잡이가 나타났다가, 강조가 끝나면 **다시 오른쪽에서 들어오는 것처럼** 보였습니다.

애니메이션이 둘이었습니다. 등장용 하나, 강조용 하나.
강조 클래스를 떼는 순간 등장 애니메이션이 **처음부터 다시 돌았습니다.**
CSS 애니메이션은 속성이 바뀌면 재시작합니다.

강조를 `::after` 로 옮겨 층을 분리했습니다.
이제 강조가 붙었다 떨어져도 본체는 건드리지 않습니다.

> **배운 것 —** 한 요소에 성격이 다른 애니메이션 두 개를 걸지 않는다. 층을 나눈다.

## 없던 스크롤바가 생겼다

미션 선택 화면에 **가로세로 스크롤바가 생겼습니다.**

강조 테두리를 요소 바깥으로 1px 넘겨 그렸는데,

```css
.hud::after { inset: -1px; }   /* ← 이 1px */
```

선택 화면에는 `overflow-y: auto` 가 걸려 있었습니다.
1px이 넘치자 브라우저가 "넘치는 내용이 있다"고 판단했습니다.

```css
.hud::after { inset: 0; }
```

> **배운 것 —** `overflow` 가 걸린 상자 안에서는 1px도 넘치면 안 된다.

## 창이 왼쪽으로 치우쳐 열렸다

가운데 열려야 할 창이 왼쪽으로 밀려 있었습니다.

길잡이 너비를 재서 피할 거리를 계산했는데, 그 순간 길잡이는
가운데 패널에서 오른쪽 상자로 **폭이 바뀌는 중**이었습니다.

| | 값 |
|---|---:|
| 잰 값 *(전환 중간값)* | **486px** |
| 실제 | **340px** |

확정값을 CSS 변수에서 읽도록 바꿨습니다.

> **배운 것 —** 움직이는 중인 물건을 자로 재지 않는다.
> 확정값은 애니메이션이 아니라 **선언**에 있다.

자세히: [시선을 한 곳에만](02-attention.md#2--창은-어디서-열려야-하나)

## 부하 시험 결과가 앞뒤가 안 맞았다

만들어 넣은 데이터가 **스스로 모순**이었습니다.

| 항목 | 값 |
|---|---|
| 동시 접속 | 200명 |
| 실패율 | **12%** |
| 응답 시간 | 550ms |
| 메모 | *"아직 여유롭습니다"* |

실패가 12%인데 응답이 빠르고 여유롭다는 건 말이 안 됩니다.
실제로는 **지연이 먼저 오고 그다음에 실패가 따라옵니다.**

모델을 다시 짜서 순서를 맞췄습니다.
(이 창은 이후 세션을 다시 설계하면서 통째로 없앴습니다.)

> **배운 것 —** 지어낸 데이터도 **인과가 맞아야** 한다. 숫자 셋 중 하나만 어긋나도
> 화면 전체가 가짜로 보인다.

## 문장과 그래프의 숫자가 달랐다

설명은 "9번 재시작됐습니다"인데 그래프는 **8번**만 그렸습니다.

그래프, 통계 숫자, 설명 문장에 각자 자기 값이 있었습니다.
그래프는 그리다 보니 8번이 됐고 문장은 처음에 적어둔 9였습니다.

그래프가 **실제로 그린 횟수를 세어** 숫자와 문장에 함께 쓰도록 바꿨습니다.

```js
memDone();   // 센 값을 #mem-rs · #mem-cnt · #mem-note 세 곳에 함께 쓴다
```

> **배운 것 —** 같은 사실을 화면 세 군데에 쓸 거면 **한 군데서 계산**한다.
> 어긋나는 순간 나머지 전부의 신뢰가 같이 떨어진다.

## 단계 이름이 "백업 파일 찾는 —" 이 됐다

진행 중 문구에서 어미만 잘라내 완료 문구를 만들었습니다.

```js
st.t.replace(/ 중…?$/, '')     // "백업 파일 찾는 중…" → "백업 파일 찾는 "
```

*"백업 파일 찾는 중…"* 에서 "중…"을 떼면 *"백업 파일 찾는"* 이 됩니다. 말이 아닙니다.

한국어는 어미가 문장을 끝내기 때문에 잘라내면 **문장이 아니게 됩니다.**
영어에서 `-ing` 를 떼는 것과 다릅니다.

각 단계에 **진행 중 문구와 완료 문구를 따로** 뒀습니다.

> **배운 것 —** 문자열을 잘라서 다른 문구를 만들지 않는다. 특히 한국어는.

## 배포 폴더가 날짜를 넘겼다

고친 것을 확인하려고 재봤는데 **여전히 안 고쳐진 값**이 나왔습니다.
코드를 몇 번 다시 봤습니다.

자정을 넘기면서 빌드 스크립트가 **새 날짜 폴더**에 결과를 썼는데
확인용 서버는 여전히 **어제 폴더**를 보고 있었습니다.

고친 코드는 한 폴더에 있고 재고 있던 건 다른 폴더였습니다.

> **배운 것 —** 측정값이 이상하면 **무엇을 재고 있는지**부터 확인한다.

---

## 그리고, 재는 도구가 두 번 틀렸다

접근성 검사와 명도 대비 계산을 직접 짜서 돌렸는데 둘 다 틀렸습니다.

| 도구가 말한 것 | 실제 |
|---|---|
| 숨어 있는데 탭으로 닿는 요소 **111개** | **29개** — `display:none` 까지 세고 있었다 |
| 명도 대비 전부 통과 | 두 곳 미달 — 반투명 배경을 계산에 안 넣었다 |

자세히: [접근성](04-accessibility.md#검사-도구가-두-번-틀렸다)

> **배운 것 —** 숫자가 예상과 크게 다르면 화면이 아니라 **자**를 먼저 본다.
